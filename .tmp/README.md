# 临时产物目录（整体 git 忽略）

存放所有运行期/验证期生成的临时产物，不进版本库（仅本 README 入库以固化目录结构约定）。

| 子目录       | 用途                            | 产生方                  |
| ------------ | ------------------------------- | ----------------------- |
| screenshots/ | e2e 自我验证的关键状态截图      | 浏览器截图（Agent）     |
| coverage/    | Vitest 覆盖率报告（text/html）  | `npm run test:coverage` |
| logs/        | dev server 等后台进程输出日志   | e2e 验证流程            |

约定：

- 目录不存在时可按需创建，子目录名保持上表固定，勿在本目录堆放其他文件。
- 本目录可随时整体清空，不影响仓库与构建。
