# MaduReader E2E：Agent 自我验证协议

本项目的 e2e 测试不使用 Playwright 等脚本测试框架，而是由 AI Agent 在每次 UI 改动后亲自执行闭环验证：

```
启动 dev server → 浏览器操作关键状态 → 截图 → 目视判定 → 有问题则修复重跑 → 恢复现场
```

## 端口约定（强制）

- 本项目专用 dev server 端口：**17973**。本项目所有端口一律不使用框架默认值（如 1420/5173），避免与其他并行开发的项目冲突。
- 端口出现点共 3 处，修改时必须同步：
  1. `vite.config.ts`（server.port）
  2. `src-tauri/tauri.conf.json`（build.devUrl）
  3. 本文件
- 新增任何服务（mock server、预览服务等）同样禁止使用知名默认端口。

## 验证流程（每次 UI 改动后必须执行）

1. 后台执行 `npm run dev`，确认 `http://localhost:17973` 可访问（可用 curl 冒烟）；dev server 输出重定向到 `.tmp/logs/dev-server.log`。
2. 用浏览器工具打开页面，按下方检查清单逐项操作。
3. 每个关键状态截图保存到 `.tmp/screenshots/`（临时目录规划见 [.tmp/README.md](../.tmp/README.md)，整体 gitignore 不进版本库）。
4. 对每张截图目视判定，发现问题回到源码修复后重跑对应项。
5. 验证结束：关闭 dev server，恢复操作中改变的状态（如主题切回默认）。

## 检查清单

- 首页空态：侧边栏、底部工具栏、占位文案正常，无布局塌陷。
- 打开 `docs/README.md`：标题、表格、代码高亮、图片渲染正确。
- 打开 `docs/advanced.md`：Mermaid/KaTeX/PlantUML 渲染为真实图形而非报错文本。
- 暗色模式：背景/文字/代码块对比度正常，无"黑底黑字"或低对比元素（最容易翻车，必查）。
- 页内查找（🔍 按钮 / Ctrl+F）：高亮与匹配计数正常。
- 幻灯片模式与缩放（50%~200%）：布局不错位。

## 判定标准

布局无塌陷、无报错文本残留、无低对比/配色错误、图表为真实图形、交互后状态符合预期。

## 产出约定

- 全部通过：在交付说明中列出已验证的状态项与截图路径。
- 存在失败：附截图路径与问题描述，定位到具体组件/样式文件。
