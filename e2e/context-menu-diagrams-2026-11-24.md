## 图形问题根因

实际 Mermaid 图形的载荷来自 HTML DOM 的 `outerHTML`。多行标签位于 `foreignObject` 内，HTML 空元素可能被序列化为 `<br>` 而不是 XML 的 `<br/>`。

旧实现用 `image/svg+xml` 解析，遇到这些标签发生 XML 解析错误，退回 800×600 兜底尺寸且保留原始的响应式 SVG。缩放和居中按兜底尺寸计算，浏览器却把 SVG 绘制成另一种尺寸，造成图形偏小、偏左上。

修复使用 HTML DOM 解析载荷，读取真实 `viewBox`，并通过 CSSOM 明确替换 SVG 根尺寸及正文遗留的最大尺寸限制。保留已有完整等比例适配、48px 安全边距、适配基准 100%、用户缩放后不抢复位的交互，不修改文档源码。
