## 修复并重跑

- 浏览器屏幕矩阵含页面缩放，曾将 16px 标签测为 20px。测量现在取消根 SVG 的屏幕变换，再映射回原始 CSS 像素；补充 0.5/1.25/2 屏幕缩放和内部变换测试。
- 缩小阅读内容时，变换前布局盒曾撑出横向滚动条。外层隔离该布局盒，正文长词换行，宽代码、表格和公式仍内部滚动，不以裁掉真实内容掩盖溢出。
- 阅读缩放改为 150% 后，旧媒体捕获监听曾在展开时恢复为 `scale(1)`。已真实复现，改为从实时 store 取得缩放，单测与真实展开/收起均重跑通过。
- 段落的 `overflow-wrap:anywhere` 曾使宽表格逐字符挤列；表格改为 `overflow-wrap:normal` 并保留内部滚动。完整重载后实测 3148px 表格内容可横向查看。
- PlantUML 相对/绝对 URL 统一缓存键，补共享请求测试；明确 `source:'plantuml'` 的迟到元数据、用户模式、CORS 失败和销毁测试均通过。
- Windows 文件锁先后使开发服务的文件监听退出。仅临时启动脚本改用轮询并排除 `.tmp`/`.agent`；正式 Vite 配置与项目端口未改。服务恢复后重载最新页面，重新截图；服务中断期间生成的截图不作为证据。
